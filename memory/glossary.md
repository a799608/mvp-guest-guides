# Glossary

Will's shorthand for MVP Rentals and this repo.

## Acronyms
| Term | Meaning | Context |
|------|---------|---------|
| MVP | MVP Rentals | Will's vacation rental business |
| TT | Towamensing Trails | Pocono community where all 6 houses are |
| TTPOA | Towamensing Trails POA | Guest registration; "TTPOA Filled" = col AD |
| GAS | Google Apps Script | Back end for dashboards and Form 2 |
| PWA | Progressive Web App | mvp-app launcher, cleaner pages |
| QA | Quality check | Usually phone_qa.py renders |

## Internal Terms
| Term | Meaning |
|------|---------|
| v1 | Archived original guide per property; content source for the generator |
| v2 | Live dark-editorial guide design (since 2026-06-03) |
| build_v2 / regen | Run `python build_v2.py` to regenerate all 6 guides |
| pill / card | One info block on a guide page |
| cat-default / beds / climate / kitchen / alert | Pill header colors (green / navy / mid green / light green / amber) |
| The Nos | House rules card |
| Amenity badges | Community badge set: $250 replacement, 3 strikes, deposit forfeit |
| Getting In | Door code, lock and parking card (unique per property) |
| Message Will / Text Will tap | Prefilled SMS button on guides |
| #checkout | Anchor the 9 AM checkout-day message links to |
| Form 2 | GAS web app (`Form2_GAS_live/Code.js` in the `mvp-rentals` repo) that unlocks codes during the stay |
| Unlock | Guest enters Reservation ID to see door/WiFi codes |
| r/ pages | Per-reservation pages: `direct_*` = direct booking, `ha_*` = probably HomeAway/Vrbo (unconfirmed) |
| landing page | Root `index.html`, admin only |
