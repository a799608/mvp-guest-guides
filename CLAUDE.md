## Preferences
- Log every guide change in CHANGELOG.md: date, Will's quote, what changed, QA result, how to revert
- Per-property wording stays different (Getting In, beds, fireplace, A/C, pets); don't standardize it
- Door and WiFi codes never go in page HTML (see docs/door_code_access.md)
- This repo is public on GitHub Pages: no secrets, codes or private guest data in any file, memory included
